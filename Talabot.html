Talabots 🚗🤖

Line Follower Delivery Robot – PRISM Event

By-Aarav jain Grade 9A

About the Project

Talabots is a line follower robot inspired by Talabat delivery robots. It follows a predefined path using sensors to simulate automated food delivery.

How It Works

  • IR sensors detect black and white lines
  • Microcontroller processes sensor data
  • Motors move the robot accordingly

Applications

  • Food delivery in malls
  • Hospital medicine delivery
  • Warehouse automation
